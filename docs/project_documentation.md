# Olist E-commerce Analytics — Project Documentation

## Project Overview
This project analyzes Olist e-commerce sales and delivery performance using Microsoft Fabric and Power BI.

## Objectives
- Analyze sales and revenue trends.
- Identify top-performing product categories.
- Evaluate delivery delays and order performance.
- Present business insights through interactive dashboards.

## Tools Used
- Microsoft Fabric
- Lakehouse
- Dataflow Gen2
- Notebooks with Python and Spark
- Power BI
- DAX

## Deliverables
- Data transformation and star-schema notebook
- Sales Overview dashboard
- Delivery Performance dashboard
- Exported dashboard PDF report

## Future Improvements
- Add customer retention analysis.
- Analyze payment methods and customer reviews.
- Add automated data refresh and monitoring.
